# Glossario

Una parola per ogni concetto, sempre la stessa in tutta l'app. Etichette in maiuscolo solo all'inizio
("Nome atleta", non "Nome Atleta"). I codici interni (es. `OL`, `doppio70m`) non si mostrano mai: si mostra
l'etichetta.

| Parola | Significato | Da non usare |
|---|---|---|
| Compagnia | la A.S.D. Compagnia Arcieri Eugubini | Società (solo per le altre società nei risultati), Club, Team |
| Atleta | un membro della compagnia che usa l'app | Utente, Arciere (nei testi dell'app) |
| Gara | una competizione nel calendario Fitarco | Torneo, Evento, Competizione |
| Tipologia | il tipo di gara: 18 m, 25 m, 25+18 m, 70 m, Doppio 70 m, 12+12, 24+24, 3D | Formato, Round |
| Famiglia | Indoor, Outdoor, Campagna, 3D | Categoria |
| Prova | una parte di gara con il suo punteggio (il 25+18 ha due prove) | Sessione, Round |
| Divisione | Arco ricurvo, Arco compound, Arco nudo, Arco istintivo, Longbow | Arco (da solo), Specialità |
| Classe | Master, Senior, Junior, Allievi, Ragazzi | Categoria, Età |
| Volée | gruppo di frecce tirate prima di andare al bersaglio | Serie, End |
| Freccia | un singolo tiro | Tiro |
| Punteggio | i punti di una freccia, una volée, una prova o una gara | Score, Risultato (per i punti) |
| Risultato | punteggio e posizione di un atleta in una gara | Esito |
| Record | il miglior punteggio personale in un tipo di prova e divisione | Primato, Best |
| Classifica | la ranking Fitarco per l'ammissione ai Campionati Italiani | Ranking, Graduatoria |
| Posizione | il posto in classifica o in una gara | Piazzamento, Rank |
| Invito | il documento della gara con programma, costi e iscrizioni | Locandina, Bando |
| Iscrizioni | il periodo in cui ci si può iscrivere a una gara | Registrazione |
| Promemoria | un avviso programmato (notifica o evento nel calendario) | Reminder, Alert |
| Allenamento | l'area personale: settimana, diario, segnapunti | Training |
| Simulazione | una gara tirata in allenamento e registrata nel segnapunti | Prova (che ha un altro significato) |
| Segnapunti | lo strumento per inserire i punteggi freccia per freccia | Scorecard |
| Aggiorna dati | leggere di nuovo i dati da Fitarco | Sincronizza (riservato alla sincronizzazione telefono/server) |
| Sincronizzazione | allineamento tra telefono e server | Sync |
